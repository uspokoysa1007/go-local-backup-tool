# go-local-backup-tool

Утилита локального инкрементного резервного копирования на Go с контролем целостности через SHA-256 хеши.

## Возможности
- Создание точных снимков (снапшотов) директорий с сохранением структуры.
- Вычисление SHA-256 хешей для каждого файла.
- Формирование структурированного JSON-манифеста бэкапа (`manifest.json`): размеры, хеши, даты модификации.
- Верификация (`verify`): проверка существующих резервных копий на повреждения данных и несанкционированные изменения.
- Подсчет статистики: сэкономленное время, объем скопированных данных, скорость работы.

## Сборка
```bash
go build -o releases/go-local-backup-tool.exe main.go
```

## Использование
```bash
# Создание резервной копии директории
./releases/go-local-backup-tool.exe -mode backup -src ./my_folder -dest ./backups

# Проверка целостности созданного бэкапа
./releases/go-local-backup-tool.exe -mode verify -manifest ./backups/2026-10-11_12-00-00/manifest.json
```
